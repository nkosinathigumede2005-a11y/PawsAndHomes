# Paws and Homes

## Project Description
Paws and Homes is a C# Windows Forms desktop application developed using Microsoft Visual Studio. It is designed to manage pet adoption and animal donations.

## Main Users
- **Admin:** Manages pet records and oversees the system.
- **Adopter:** Views available pets and manages adoption-related activities.
- **Donor:** Donates pets to be listed in the system for adoption.

## Supported Animals
The system caters for dogs, cats, birds and rabbits.

## Technologies Used
- C#
- Windows Forms
- Microsoft Visual Studio
- Text files for data storage

## Main Features
- User registration and login
- Role-based access for Admin, Adopter and Donor
- Pet information management
- Pet images
- Pet adoption and donation management

## How to Run
1. Install Microsoft Visual Studio with the .NET desktop development workload.
2. Clone or download this repository.
3. Open the `.sln` solution file in Visual Studio.
4. Restore any required dependencies.
5. Build and run the project.
